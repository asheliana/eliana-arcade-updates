# Eliana Arcade - downloads

Finished builds of Eliana Arcade. The app checks this page for updates by itself.

Get the latest version from **[Releases](https://github.com/asheliana/eliana-arcade-updates/releases/latest)**:

- **Windows**: `ElianaArcade-<version>-portable.exe`
- **Android**: `ElianaArcade-<version>.apk`

Once installed, Eliana Arcade keeps itself up to date: it checks every night and from Settings > Check for updates.

## Mac

Eliana Arcade doesn't run on Mac yet. A Mac version is planned, and it'll be properly signed and approved by Apple so it opens without warnings. Keep an eye on this page: when it's ready, the Mac download will appear here alongside the others.
