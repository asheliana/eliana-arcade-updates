# Eliana Arcade - downloads

Finished builds of Eliana Arcade. The app checks this page for updates by itself.

Get the latest version from **[Releases](https://github.com/asheliana/eliana-arcade-updates/releases/latest)**:

- **Windows**: `ElianaArcade-<version>-portable.exe`
- **Android**: `ElianaArcade-<version>.apk`
